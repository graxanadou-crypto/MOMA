MoMA 1998 v1.3 Game UI

ChallengeモードのUIを大幅改修。

PC:
- 上段: CPU情報（ライフ、手札枚数をカード裏面で表示、ライブラリー、戦場、墓地）
- 中央: プレイヤー戦場
- 下段: マナ、手札、ログ
- 右側: 選択カード詳細
- 上部固定HUD: ドロー / メイン / 対戦状況 / ターン終了 / 戻す
- 勝敗時にゲーム風VICTORY / DEFEATオーバーレイ

スマホ:
- CPU情報をコンパクト化
- CPU手札をカード裏面で視覚化
- プレイヤー手札の下部固定UIはv1.1から継続
- 主要操作を上部HUDと下部固定バーの両方からアクセス可能

ゲームロジックはv1.2 Challenge αを維持。
